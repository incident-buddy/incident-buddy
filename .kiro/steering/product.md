# Product Overview

incident-buddy は Slack からインシデントを宣言・管理するセルフホスト型ボット。Firestore にインシデント情報を永続化し、チャンネルへ通知する。エラーメッセージはそのまま Slack に表示してよい（セルフホスト前提のため難読化不要）。

## Core Capabilities

- **インシデント宣言** — `/inc` コマンドでタイトル・重大度・説明を入力してインシデントを作成
- **チャンネルトピック自動設定** — 作成時に `[{severity}] {title} - 対応中`、解決時に `[Resolved] {title}` を設定
- **対応者アサイン** — ウェルカムメッセージのロールボタンで担当者を登録（コマンダー・調査担当など）
- **インシデント一覧** — `/inc list` でオープン中のインシデントを ephemeral 表示
- **設定確認** — `/inc config` で重大度・サービス・通知ルール・ロール設定を表示

## Target Use Cases

- 開発チームが Slack から離れずにインシデント対応を開始・管理する
- 重大度別の通知ルールで適切な担当者・チームに自動連絡する
- タイムラインでインシデントの経緯を記録・共有する

## Value Proposition

Markdown ファイル（`INCIDENT_CONFIG_PATH`）で重大度・サービス・通知ルール・ロールをカスタマイズ可能。設定ファイル不要でも Critical/High/Medium/Low のデフォルト値で即起動できる。セルフホスト型のため組織のSlackワークスペースに閉じた運用が可能。
